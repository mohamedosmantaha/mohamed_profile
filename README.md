# Eng. Mohammed - Personal Portfolio Website

A complete modern personal portfolio website built with HTML5, CSS3, and Vanilla JavaScript.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices.
- **Modern UI**: Dark/gray gradient background, clean minimal navigation, and smooth animations.
- **Typing Animation**: Dynamic typewriter effect in the hero section.
- **Scroll Reveal**: Elements smoothly animate into view as you scroll down the page.
- **Animated Statistics**: Number counters in the About section animate when visible.
- **Portfolio Filtering**: Projects can be filtered by category (Web, Java, PHP, Database).
- **Contact Form Validation**: Client-side form validation and success message simulation.
- **Sticky Navigation**: Navbar background changes opacity when scrolling down.
- **Back to Top Button**: Convenient button to scroll back to the top.

## Technologies Used

- HTML5 (Semantic Structure)
- CSS3 (Custom Properties, Flexbox, Grid, Animations, Transitions)
- Vanilla JavaScript (DOM Manipulation, Events, Intersection APIs)
- Google Fonts (Inter, Playfair Display)
- FontAwesome (Icons)

## Setup Instructions

1. Clone or download the repository to your local machine.
2. Replace the placeholder images in the `assets/` folder with your own actual images. Ensure they have the same names (or update the names in `index.html`).
3. Open `index.html` in your web browser. No local server is strictly required, though using a live server (like VS Code Live Server) is recommended for development.

## Customization

To edit the contents of the portfolio:
- **Text & Links**: Open `index.html` and edit the text inside tags like `<h1>`, `<p>`, `<h3>`, etc.
- **Colors & Fonts**: Open `css/style.css` and edit the variables inside the `:root` pseudo-class at the top of the file.
- **Typing Text**: Open `js/script.js` and look for the `words` array inside the Typing Animation section.

## Design Inspiration

The design emphasizes an elegant, premium feel tailored for a Software Engineering student aspiring to showcase projects, skills, and articles. It utilizes a dark theme with white typography and a soft accent color to highlight interactive elements.
